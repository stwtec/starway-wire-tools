FAQ

1. What does each field in an M27500 part number mean?

The basic structure is M27500 - coverage/color code - component AWG - Component Wire Code - number of component wires - Shield Code - Jacket Code. Example: M27500-8RC2S06 uses 8 AWG M22759/11 component wire, two component wires, silver-plated copper round shielding, and a white PTFE tape jacket.

2. Why does the first coverage/color field include codes such as -, C, F, and H?

This field combines shield coverage with the component-wire identification method. For example, "-" is the 85% Table III A preferred method, C is the 90% Table III A preferred method, and F/H correspond to Table III B.

3. Why can some valid part-number combinations be formed even when dimensions or weight are not shown?

The general MIL-DTL-27500 numbering system allows one to fifteen component wires, while the detailed product tables in the supplied Thermax PDF mainly provide dimensions and weights for one- to four-conductor constructions. When the supplied PDFs do not provide a value, this page reports that it is not provided rather than estimating it.

4. When is a TE SPEC 55 part number shown?

When the selected component-wire code is SB-ST, corresponding to SAE AS22759/32-35 or /41-46, the page shows the TE SPEC 55 component-wire cross-reference. When the entered shield, jacket, conductor count, coverage/color method, and AWG can be uniquely cross-referenced from the supplied TE catalog, a complete TE cable cross-reference is also shown. TE states that its part-numbering system is a cross-reference only and is not meant for part creation, so the final ordering number should be confirmed with TE.
